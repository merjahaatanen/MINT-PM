# Operator Troubleshooting Checklist: Holz-Her Saw (EQ ID 135)

## Troubleshooting
| Issue | Symptoms | Troubleshooting Steps | Avg. Fix Time | When to Call Maintenance |
|---|---|---|---|---|
| Air leak / Pneumatic error | - Error code 0013 – Pneumatics<br>- Machine stops cutting mid‑cut<br>- Audible air hiss or whistling<br>- Gripper dragging on table surface<br>- Machine powers off unexpectedly<br>- “Pneumatics” error message on screen | - Turn the machine OFF and isolate the air supply.<br>- Visually inspect all exposed air hoses and connectors for cracks, splits, or loose fittings.<br>- Listen closely for hissing near the program fence, gripper cylinders, and solenoid valves.<br>- Tighten any loose connectors you can reach without tools.<br>- If a damaged hose or connector is found, STOP the machine and notify Maintenance.<br>- Reset the fault via the control panel (Tools → Calibrate) and restart the machine if no leak is evident. | ~0.6 hrs (42 work orders) | Call Maintenance if you discover a cracked or broken hose, a loose or damaged connector, or if the error persists after the visual check. |
| Missing/Damaged air accessories (nozzles, caps, balls, bearings, cups) | - Lack of suction on the air table<br>- Air table not holding sheet firmly<br>- “Air table not working” messages<br>- Missing or damaged air caps/balls on table<br>- No airflow from one or more air nozzles | - Verify that all air nozzles on the table are present and not blocked.<br>- Check that air caps (white balls) are installed on each nozzle.<br>- Ensure air bearings/air cups are seated correctly.<br>- Remove any debris or tape covering the nozzles.<br>- If any nozzle, cap, ball or bearing is missing or broken, replace the part (see Parts column). | ~0.3 hrs (11 work orders) | Call Maintenance if a nozzle, cap, ball, bearing or cup is broken or missing and cannot be re‑installed by the operator. |
| Debris causing cut stoppage | - Cut stops mid‑cut without error code<br>- Pieces of particle board or MDF fall into the machine<br>- Blade or carriage jams after a cut<br>- Operator hears material “clicking” or “clunk” | - STOP the machine immediately.<br>- Open the machine covers and remove any fallen pieces, slivers or debris using a safe tool (e.g., pulling rod, flashlight).<br>- Clear the area around the program fence and blade compartment.<br>- Verify the carriage can move freely before restarting.<br>- If debris is lodged in a hard‑to‑reach area, request Maintenance. | ~0.4 hrs (7 work orders) | Call Maintenance if you cannot remove the material or the carriage remains stuck after cleaning. |
| Sensor & width stop issues | - Width‑stop or “Width Drag” pop‑up messages<br>- Dirty or obstructed width sensor<br‑- Inconsistent width stop positioning<br>- Machine halts after a few cuts with no pneumatic code | - Clean the width sensor with a clean ear‑bud or cotton swab (no liquids).<br>- Press “OK” on the pop‑up, then go to **Tools → Calibrate** and run the calibration routine.<br>- Adjust the width‑stop position manually if it is out of range (refer to operator guide).<br>- Verify the sensor is unobstructed before restarting. | ~0.3 hrs (6 work orders) | Call Maintenance if the sensor remains dirty after cleaning or the width‑stop does not calibrate correctly. |
| Mechanical part failures (push arm, sponge, pushers, e‑stop, over‑tightened screws) | - Pushing arm does not raise/lower<br>- Rubber sponge under beam missing or worn<br>- Pushers/belts broken or detached<br>- Emergency‑stop button fell off<br>- Screws stripped or over‑tightened | - Inspect the pushing arm and replace any broken screw (use the supplied replacement screw).<br>- Replace the rubber sponge under the beam if worn (part #2870657).<br>- Re‑attach a fallen emergency‑stop button securely.<br>- Loosen any over‑tightened screws (e.g., cap screw on blade holder).<br>- Verify movement after each adjustment. | ~1.1 hrs (6 work orders) | Call Maintenance for any broken structural components (push arms, pushers, missing screws) or if you cannot re‑secure the e‑stop safely. |
| Blade problems (noise, not raising, set‑screw stripped) | - Blade stops mid‑cut and does not return home<br>- Loud grinding or knocking noise from blade<br>- Blade holder set‑screw stripped, blade cannot be removed | - Check that the blade is not jammed with material; clear any debris.<br>- If the blade is noisy, replace it with a fresh blade.<br>- Use channel locks or a screw extractor to remove a stripped set‑screw and replace with new hardware.<br>- After blade replacement, run a test cut to confirm normal operation. | ~0.4 hrs (3 work orders) | Call Maintenance if the blade remains stuck after you have cleared debris or if the set‑screw cannot be removed safely. |
| Gear & carriage home issues | - Loud grinding or banging when carriage returns home<br>- Carriage does not slow down or stops abruptly<br>- Motor and sprocket appear mis‑aligned | - Power OFF the machine and release the carriage lock.<br>- Visually inspect the motor sprocket and drive gear for alignment; tighten any loose bolts.<br>- Replace any broken bolts or studs and add anti‑vibration washers with Loctite as needed.<br>- Reset the machine and run a cycle to verify smooth carriage movement. | ~3.3 hrs (3 work orders) | Call Maintenance for any broken bolts, mis‑aligned motor/sprocket, or persistent grinding noises. |
| Computer/PC issues | - Saw computer screen blank or unresponsive<br>- “Low disk space” warning on C: drive<br>- Width‑stop position off after PC upgrade | - Verify that the PC is powered and all cables (label printer, Ethernet) are connected.<br>- If low disk space, notify IT to expand the C: drive (do not delete system files).<br>- After a PC upgrade, run the width‑stop calibration routine (Tools → Calibrate). | ~8.5 hrs (2 work orders) | Call Maintenance/IT for PC replacement, hardware upgrades, or persistent software errors. |
| Dust collection / duct clog | - Excess dust accumulation on machine and floor<br>- Duct hose appears blocked or punctured | - Replace the flexible duct hose (part #53145K681) with a new 12 ft length.<br>- Inspect the duct for punctures and clear any debris.<br>- Verify airflow by running the dust‑collection system for a short cycle. | 1.5 hrs (1 work order) | Call Maintenance if the duct cannot be cleared or the hose is damaged. |
